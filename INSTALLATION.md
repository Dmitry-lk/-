# Инструкция по установке и запуску

## Системные требования
- Node.js версии 18 или выше
- npm (устанавливается вместе с Node.js)

## Установка Node.js (если не установлен)

### Windows:
1. Скачайте установщик с https://nodejs.org/
2. Запустите установщик и следуйте инструкциям
3. Перезагрузите компьютер

### macOS:
1. Скачайте установщик с https://nodejs.org/
2. Или используйте Homebrew: `brew install node`

### Linux:
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
```

## Запуск приложения

### Шаг 1: Распакуйте архив
Распакуйте все файлы в любую папку на вашем компьютере

### Шаг 2: Откройте терминал/командную строку

**Windows:**
- Нажмите Win + R
- Введите `cmd` и нажмите Enter
- Перейдите в папку с проектом: `cd путь\к\папке\проекта`

**macOS/Linux:**
- Откройте Terminal
- Перейдите в папку с проектом: `cd путь/к/папке/проекта`

### Шаг 3: Установите зависимости
```bash
npm install
```
*Это займёт 2-5 минут*

### Шаг 4: Запустите приложение
```bash
npm run dev
```

### Шаг 5: Откройте в браузере
Откройте браузер и перейдите по адресу:
```
http://localhost:5173
```

## Готово! 🎉

Приложение запущено и доступно в браузере.

## Возможные проблемы

### "npm не найден"
- Node.js не установлен или не добавлен в PATH
- Решение: Переустановите Node.js и перезагрузите компьютер

### Порт 5173 занят
- Приложение автоматически выберет другой порт (5174, 5175 и т.д.)
- Смотрите в терминале, какой порт был выбран

### Ошибки при установке зависимостей
```bash
# Попробуйте очистить кэш и переустановить
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

## Функционал системы

### 1. Главная панель (Dashboard)
- Общая статистика склада
- Критические уведомления
- Недавние перемещения
- Запчасти с отрицательным остатком

### 2. Каталог запчастей
- Полный список запчастей с артикулами и OEM-номерами
- Информация о стоимости и поставщиках
- Статус: новые/б/у/восстановленные
- Поиск и фильтрация

### 3. Движение запчастей
- История всех перемещений
- Привязка к оборудованию и сотрудникам
- Фотофиксация
- Типы операций: выдача, возврат, списание, перемещение

### 4. Оборудование
- Реестр оборудования с паспортами TOIR
- Категории: пилорамы, кромкообрезные станки и т.д.
- График обслуживания

### 5. Отчёты
- Аналитика движения запчастей
- Генерация документов для 1С
- Экспорт данных

### 6. Настройки
- Синхронизация с 1С
- Настройка Telegram уведомлений
- Управление пользователями
