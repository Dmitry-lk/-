
## 📋 Основной функционал

### ✅ Реализовано в демо-версии:

1. **Синхронизация с 1С**
   - Справочник запчастей (наименование, артикул, OEM)
   - Автообновление остатков
   - Генерация документов "Требование-накладная"

2. **Учёт перемещений**
   - Фиксация: откуда → куда (цех, станок, резерв)
   - Типы операций: выдача, возврат, списание, перемещение
   - Привязка к оборудованию через паспорт TOIR
   - История с временем и пользователем

3. **Идентификация и контроль**
   - Ответственный сотрудник при каждом перемещении
   - Фотофиксация до/после операции
   - Комментарии к каждому перемещению
   - Запрет внесения данных задним числом

4. **Работа с запчастями**
   - Новые / Б/У / Восстановленные
   - Разукомплектование агрегатов
   - Отрицательные остатки (отпуск в минус)
   - Дата поступления на склад
   - Стоимость и контрагенты

5. **Уведомления и контроль**
   - Критически низкие остатки
   - Telegram/Админ панель уведомления
   - Создание заявок на недостающие запчасти

6. **Интеграция**
   - Маршруты обходов и плановое ТО
   - Группировка по категориям оборудования
   - Выгрузка в 1С после подтверждения ЛПР

## 🎯 Основные возможности

### Панель управления (Dashboard)
- Общая статистика: запчасти на складе, критические остатки
- Alerts: отрицательные остатки, низкий запас
- Недавние перемещения
- Документы на утверждение

### Каталог запчастей
- Полная информация по каждой запчасти
- Артикулы, OEM-номера, категории
- Остатки по складам
- Стоимость и поставщики
- Фильтрация и поиск

### Движение запчастей
- Полная история операций
- Фотофиксация
- Привязка к оборудованию и сотрудникам
- Комментарии
- Статусы: на утверждении, утверждено, отклонено

### Реестр оборудования
- Паспорта TOIR
- Категории оборудования
- График обслуживания
- История использования запчастей

### Отчёты
- Аналитика движения
- Остатки по складам
- Стоимостной учёт
- Генерация документов для 1С

### Исходящие данные в 1С:

## 📊 Структура данных

### Запчасти (Parts)
```typescript
{
  id: string
  name: string
  article: string
  oem: string
  category: string
  quantity: number
  minQuantity: number
  condition: 'new' | 'used' | 'repaired'
  warehouse: string
  cost: number
  supplier: string
  receivedDate: string
}
```

### Перемещения (Movements)
```typescript
{
  id: string
  partId: string
  type: 'issue' | 'return' | 'write-off' | 'transfer'
  from: string
  to: string
  quantity: number
  user: string
  equipment?: string
  photos: string[]
  comment: string
  status: 'pending' | 'approved' | 'rejected'
  date: string
}
```
