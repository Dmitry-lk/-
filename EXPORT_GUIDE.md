# Как отправить проект другому человеку

## Вариант 1: ZIP архив (Рекомендуется)

### Что нужно сделать:

1. **Создайте ZIP архив со всеми файлами проекта**
   - Windows: Правой кнопкой на папку → "Отправить" → "Сжатая ZIP-папка"
   - macOS: Правой кнопкой на папку → "Сжать"
   - Linux: `zip -r warehouse-system.zip .`

2. **Отправьте архив**
   - Email (если размер < 25MB)
   - Google Drive / Яндекс.Диск
   - Dropbox / OneDrive
   - WeTransfer (до 2GB бесплатно)
   - Telegram / WhatsApp

3. **Инструкция получателю:**
   ```
   1. Распакуйте архив
   2. Установите Node.js с https://nodejs.org (если нет)
   3. Windows: Запустите файл START.bat
      macOS/Linux: Запустите файл START.sh
   4. Откройте в браузере http://localhost:5173
   ```

## Вариант 2: GitHub (для технических специалистов)

### Если у вас есть аккаунт GitHub:

```bash
# Инициализация git
git init

# Добавление файлов
git add .

# Коммит
git commit -m "Initial commit: Warehouse Management System"

# Создайте репозиторий на github.com
# Затем подключите и запушьте:
git remote add origin https://github.com/ваш-username/warehouse-system.git
git push -u origin main
```

**Отправьте получателю ссылку на репозиторий**

Получатель должен:
```bash
git clone https://github.com/ваш-username/warehouse-system.git
cd warehouse-system
npm install
npm run dev
```

## Вариант 3: Онлайн демо (без установки)

### Деплой на Vercel (бесплатно):

1. Создайте аккаунт на https://vercel.com
2. Установите Vercel CLI:
   ```bash
   npm install -g vercel
   ```
3. Деплой:
   ```bash
   vercel
   ```
4. Следуйте инструкциям в терминале
5. Получите ссылку вида: `https://ваш-проект.vercel.app`

**Отправьте эту ссылку** - человек сможет открыть систему в браузере без установки!

### Деплой на Netlify (альтернатива):

1. Создайте аккаунт на https://netlify.com
2. Перетащите папку проекта в веб-интерфейс Netlify
3. Получите ссылку на сайт

## Вариант 4: Локальная сеть

Если вы в одной сети (офис):

```bash
# Запустите проект
npm run dev

# Узнайте свой IP
# Windows: ipconfig
# macOS/Linux: ifconfig или ip addr

# Проект будет доступен по адресу:
# http://ваш-ip:5173
```

Другой человек откроет этот адрес в браузере.

## ⚠️ Что НЕ нужно отправлять

При создании архива **ИСКЛЮЧИТЕ** эти папки (они большие и не нужны):

- `node_modules/` - установится автоматически
- `.git/` - история изменений
- `dist/` или `build/` - сгенерированные файлы

## 📦 Минимальный набор файлов

```
warehouse-system/

├── vite.config.ts     ✓
```

## 🎯 Рекомендация

**Для быстрой демонстрации:** Вариант 3 (Vercel) - человек сразу откроет ссылку  
**Для работы с кодом:** Вариант 1 (ZIP) или Вариант 2 (GitHub)  
**Для презентации в офисе:** Вариант 4 (локальная сеть)

## 🆘 Если возникли проблемы

1. **Архив слишком большой**
   - Удалите `node_modules/` перед архивированием
   - Используйте облачные сервисы

2. **Не открывается на другом компьютере**
   - Убедитесь, что получатель установил Node.js
   - Проверьте, что все файлы распакованы

3. **Ошибки при npm install**
   - Проверьте подключение к интернету
   - Попробуйте: `npm cache clean --force`
